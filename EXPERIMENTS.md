# Experiment log

Every run, including the ones that did not work, in date order. CV = out-of-fold ROC AUC on 5-fold stratified CV.
Comparisons are paired: the same fold seeds (42/7/2026, later also 11/123/31337/777) for every model, and a change
is kept only if it wins on every seed by more than the seed-to-seed noise (~0.0002-0.0003 AUC).
Scripts no longer in the final pipeline are in `experiments/archive/` (paths below are as they were at the time).

## Highlights

| step | CV AUC | public LB |
|---|---|---|
| LightGBM, raw features | 0.94576 | - |
| + target encoding of exact numeric values, drop no-signal raw columns ("ei") | 0.94719 | 0.94837 |
| + velocity residual, 12 digit keys, shallow trees + MLP rank blend, zone 1 (submission 2) | 0.94990 | 0.94997 |
| + EBM in the blend, 7 fold seeds (submission 3) | 0.95030 | 0.95027 |
| + logistic regression with 42 digit keys, trees with the same keys, LR stacker (stack v4, 3 fold seeds) | 0.95112 | not submitted |
| bagged LightGBM, 7 fold seeds (stack v5, submission 4) | 0.95121 | 0.95121 |

What did not help (all logged below): the original 20k-row dataset, deeper trees, CatBoost depth 6, RealMLP,
specialist models for hard rows, sample weights, piecewise-linear NN inputs, TE smoothing / regularization tweaks,
new k42 EBM / MLP members on top of the stack.

## Glossary

| code | meaning |
|---|---|
| TE | target encoding: each value replaced by the smoothed fraud rate of that value, computed out-of-fold |
| ei | TE of 8 numerics' exact values + raw features minus 5 no-signal columns |
| eiv / eivd | ei + vel_ex (velocity minus its expected value given txn count and hours) / + TE of 12 digit keys |
| digit keys | how a number is written: last digit, number of decimals, fractional part (12 keys) |
| k42 | 42 numeric digit keys: 7 per float column (cent, integer, tens, tenths, first digit, first 2 digits, length) |
| lgb_l3, xgb_d2 | LightGBM with 3 leaves per tree, XGBoost depth 2 (very shallow trees) |
| _x3 | average of 3 models with different random seeds (bagging) |
| b1023 | LightGBM max_bin 1023 |
| mlp_d | MLP with the 12 digit keys |
| glm_plain | logistic regression on scaled numerics, one-hot categoricals and logit TE of every value and the 42 keys |
| EBM | Explainable Boosting Machine (additive model with 10 pairwise terms, interpret library) |
| zone 1 | rows with merchant_risk_score < 13.1 (no fraud in train below it) put at the bottom of the ranking |
| hard / quiet rows | rows with 0-1 / 0 of the strong fraud signals (cvv retries, risky merchant, no auth, ...) |
| stack | logistic regression on the members' out-of-fold scores, scored on the same folds (nested) |
